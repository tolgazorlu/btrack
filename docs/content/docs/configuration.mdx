# Configuration

btrack stores configuration in `~/.config/btrack/config.yaml`.

## Setting Options

Use `btrack config` to set values without editing the file directly:

### Working Hours

```bash
btrack config hours 8
```

Sets the expected number of working hours per day. Used in progress indicators and daily summaries.

### Idle Timeout

```bash
btrack config idle 30
```

Sets the idle timeout in minutes. If btrack detects no activity for this period, it warns you that your session may have drifted.

### Max Session Length

```bash
btrack config max-hours 12
```

Caps any single session at N hours (0 = off). A session that runs past the cap
is auto-stopped by the daemon, backdated to `start + cap`, and tagged `#runaway`.

### Project Rates

```bash
btrack config project myapp rate 150
```

Sets the hourly billing rate recorded for project `myapp`.

## Config File

Location: `~/.config/btrack/config.yaml`

```yaml
database:
  # sqlite_path: ""

work:
  daily_hours: 8      # target working hours per day
  # idle_minutes: 0   # auto-stop after N minutes with no btrack activity (0 = off)
  # max_hours: 12     # hard cap on a single session's duration (0 = off)

projects:
  myapp:
    rate: 150
  clientco:
    rate: 120

daemon:
  # socket_path: ""
  # pid_file: ""
```

Sessions are always stored in SQLite under the btrack data directory.

## Viewing Config

```bash
btrack config
```

Prints the current configuration as YAML.
