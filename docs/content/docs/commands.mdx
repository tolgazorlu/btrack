# Command Reference

Every command runs directly from your shell; `btrack --help` prints the full reference.

## Core Workflow

| Command | Alias | Description |
|---------|-------|-------------|
| `btrack start "description"` | `btrack s` | Start a new tracking session |
| `btrack note "text"` | `btrack n` | Add a note to the active session |
| `btrack note "text" --session N` | `btrack n --session N` | Add a note to a specific past session |
| `btrack stop` | `btrack x` | Stop the active session (closing message optional) |
| `btrack stop -m "message"` | `btrack x -m` | Stop with a final closing message |
| `btrack switch "description"` | `btrack sw` | Stop current session and start a new one |
| `btrack resume` | `btrack r` | Resume the most recently stopped session |
| `btrack add "task" --from 14:03 --to 15:10` | `btrack a` | Record a finished session with explicit times |
| `btrack w` | | Live status display with elapsed time |

## History (`btrack h`)

| Flag | Description |
|------|-------------|
| _(none)_ | Show today's sessions as a tree |
| `yesterday` | Show yesterday's sessions |
| `YYYY-MM-DD` | Show sessions for a specific date |
| `-w` | Show this week's sessions |
| `-m` | Show this month's sessions |
| `-y` | Show this year's sessions |
| `-n N` | Show last N sessions as a table |
| `-n N -v` | Table view with checkpoint notes |
| `-l N` | Show last N hours |
| `-p <name>` | Filter by project name |

### Examples

```bash
btrack h              # today
btrack h yesterday
btrack h 2026-05-01
btrack h -w           # this week
btrack h -m           # this month
btrack h -p myapp     # sessions for project "myapp"
btrack h -n 10        # last 10 sessions as a table
btrack h -n 10 -v     # with notes
```

## Projects

| Command | Description |
|---------|-------------|
| `btrack projects` | List all known projects |
| `btrack init` | Interactive project setup wizard |
| `btrack config project <name> rate <N>` | Set hourly rate for a project |

See [Projects](/docs/projects) for full documentation.

## Session Editing

```bash
btrack h -n 20                         # find session IDs
btrack edit 42 -t "new task name"
btrack edit 42 --start 09:00 --end 17:30
btrack edit 42 -p myapp -m "done #bugfix"
```

## Export

```bash
btrack export                          # CSV to stdout
btrack export --format json --out f    # JSON to a file
btrack export -p myapp --days 30       # one project, one month
```

See [Export](/docs/export).
